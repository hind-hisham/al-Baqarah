# خريطة حفظ البقرة

موقع لمساعدتك على حفظ سورة البقرة في أسبوع: خطة أيام، خرائط ذهنية، تدريب على الربط بين الآيات، جداول للفواصل والمتشابهات، وشرح للآيات مع أسباب النزول.

- الإطار: Next.js (App Router) بلغة JavaScript
- التنسيق: Tailwind CSS (الإصدار 3)
- لا يوجد تسجيل دخول ولا قاعدة بيانات. بيانات المستخدم (الأيام المنجزة، الآيات المحفوظة، قائمة التكرار، إعدادات التدريب) تُحفظ في `localStorage` داخل متصفحه.

## التشغيل

```bash
npm install
npm run dev      # التطوير: http://localhost:3000
npm run build    # بناء نسخة الإنتاج
npm start        # تشغيل النسخة المبنية
```

يحتاج Node.js الإصدار 18.18 أو أحدث. الخطوط تُحمَّل من Google Fonts عبر `next/font` أثناء البناء، فيلزم اتصال بالإنترنت في `npm run build` أول مرة.

## هيكل المشروع

```
src/
├── app/                  الصفحات (كل مجلد = رابط)
│   ├── layout.js         القالب العام: الخطوط والشريط العلوي
│   ├── globals.css       الألوان (فاتح/داكن) وأصناف جاهزة مثل .card و .btn
│   ├── page.js           /           خطة الأسبوع
│   ├── maps/[id]/        /maps/1     الخرائط الذهنية (master أو 1 إلى 6)
│   ├── practice/         /practice   تدريب الربط
│   ├── tafsir/[day]/     /tafsir/1   الشرح مع أسباب النزول
│   ├── asbab/            /asbab      قائمة أسباب النزول
│   ├── endings/          /endings    الفواصل المتكررة
│   └── similar/          /similar    المتشابهات
├── components/           أجزاء الواجهة القابلة لإعادة الاستعمال
├── data/                 كل المحتوى (نصوص وأرقام) بعيدا عن الواجهة
├── lib/                  دوال مساعدة (لا تحتوي واجهة)
└── config/               إعدادات صغيرة: روابط الشريط، مفاتيح التخزين
```

قاعدة تسهّل القراءة: **المحتوى في `data/` والمنطق في `lib/` والشكل في `components/` و `app/`.**

## كيف أعدّل المحتوى؟

| أريد أن… | أعدّل الملف |
|---|---|
| أغيّر توزيع الآيات على الأيام | `src/data/days.js` |
| أعدّل شرح آية | `src/data/tafsir.js` (المفتاح = رقم الآية) |
| أضيف سبب نزول | `src/data/asbab.js` (أضف عنصرا جديدا) |
| أعدّل خريطة ذهنية أو أضيف فرعا | `src/data/maps.js` |
| أضيف مجموعة متشابهات | `src/data/similar.js` (أرقام الآيات + تلميح، والتظليل تلقائي) |
| أضيف تنبيها على فاصلة | `src/data/endingHints.js` |
| أغيّر برنامج اليوم والقواعد | `src/data/routine.js` |
| أغيّر الألوان | `src/app/globals.css` (متغيرات `--primary` وغيرها) |

ملاحظة: الشرح وأسباب النزول مكتوبان بصياغة مختصرة للاستعانة على الحفظ والفهم، وفي `asbab.js` حقل `grade` يبيّن درجة توثيق كل رواية. راجع كتب التفسير المعتمدة للتحقق أو التوسع.

## كيف أضيف صفحة جديدة؟

مثال: صفحة «ملاحظاتي» على الرابط `/notes`.

1. أنشئ الملف `src/app/notes/page.js`:

```jsx
export default function NotesPage() {
  return (
    <>
      <h1 className="page-title">ملاحظاتي</h1>
      <p className="page-lead">وصف قصير للصفحة.</p>
    </>
  );
}
```

2. أضف سطرا في `src/config/nav.js` ليظهر في الشريط العلوي:

```js
{ href: '/notes', label: 'ملاحظاتي' },
```

هذا كل شيء. الصفحة تأخذ القالب والخطوط والألوان تلقائيا.

## كيف أحفظ بيانات جديدة للمستخدم؟

استعمل الخطاف `useLocalStorage` في أي مكوّن يبدأ بـ `'use client'`:

```jsx
'use client';
import { useLocalStorage } from '@/lib/storage';

export default function NoteBox() {
  const [note, setNote] = useLocalStorage('bq-note', '');
  return <textarea value={note} onChange={(e) => setNote(e.target.value)} />;
}
```

يعمل مثل `useState` لكن القيمة تبقى بعد إغلاق الصفحة. ضع اسم المفتاح في `src/config/storageKeys.js` ليبقى منظما.

## متى أستعمل `'use client'`؟

- الصفحات والمكوّنات التي تعرض محتوى فقط تعمل على الخادم (الافتراضي) ولا تحتاج شيئا.
- أي مكوّن يستعمل `useState` أو `useEffect` أو التخزين أو الأحداث (`onClick`) يجب أن يبدأ بـ `'use client'`.
  في المشروع: `NavBar` و `PlanBoard` و `Practice` و `MemorizedToggle`.
